# Data Warehousing & Mining 📊

A practical collection of **Data Warehousing and Data Mining (DWM)** coursework and task work.

This repository is maintained as a record of the practical side of the subject — from working with data and OLAP concepts to implementing data-mining techniques and keeping the related execution evidence together.

## 🔎 What this repository is about

The coursework focuses on understanding how data can be **organized, processed, analyzed and mined for useful patterns**.

Some of the practical areas covered include:

- **OLAP operations** — Slice, Dice, Roll-up and Drill-down
- **Data processing and representation** using Python / NumPy
- **Association Rule Mining** and FP-Growth
- **External sorting and large-data processing concepts**
- Practical task outputs and execution screenshots

## 🛠️ Tools & Technologies

**Python · NumPy · Jupyter Notebook · Data Warehousing · Data Mining · PostgreSQL · VS Code**

## 📁 Repository structure

The repository contains practical task implementations along with screenshots used as evidence for the coursework.

| Type | Purpose |
| --- | --- |
| 📓 Jupyter Notebooks | Practical implementations and experiments |
| 🖼️ Screenshots | Execution and submission evidence |
| 🗃️ Data / configuration files | Supporting material used during practical work |

## 🎯 Learning goal

The main goal of this work is not just to run an algorithm, but to understand **why the technique is used, how the data is prepared, and what the resulting output means**.

The practical exercises connect the concepts taught in DWM with hands-on implementation, making it easier to understand the complete flow from data preparation to analysis and pattern discovery.
